メンバー管理

ここに登録したメールアドレスの人だけがアプリを使えます。「管理者」にした人は、フォーマット編集・集計・メンバー管理もできます。

データのバックアップ（CSV）

Excelでそのまま開けるCSVファイルでダウンロードします。定期的に保存しておくと安心です。

訪問先の読み取り直し

登録済みの訪問先のうち、店舗名に住所などが混ざっているもの・県/市/区や業種が空のものを、Googleマップのリンクから読み取り直して、店舗名／都道府県／市／区／業種／営業時間を別々の項目に入れ直します。

Claude Code 連携

Claude Codeでデモサイトを作ったとき、そのURLを案件番号の訪問先に自動で登録できます（初回だけNetlifyの設定が必要です。手順は管理者向けメモを参照）。
